# Duo Climb Control Room — landing page

Static landing page for a personal Riot Developer Portal application.

## Fastest free hosting option: GitHub Pages

1. Create a new public GitHub repository, for example `duo-climb-control-room`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)` and save.
6. GitHub will give you a URL similar to:
   `https://YOURNAME.github.io/duo-climb-control-room/`
7. Paste that URL into your Riot personal project application.

Do not put your Riot API key in this repository or in `index.html`.
