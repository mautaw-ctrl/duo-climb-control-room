What the project does

Rank tracking

Displays current Solo/Duo tier, division, LP, wins, losses, and win rate for both players.

Match analysis

Reads recent ranked match history to compare KDA, CS/min, damage/min, gold/min, vision, deaths, and role/champion results.

Duo analysis

Finds shared matches and summarizes duo win rate, champion pairings, recent form, side results, and selected objective statistics.

Improvement trends

Compares recent samples such as last 10 games versus previous 10 and tracks personal performance targets over time.

Climb goals

Lets us set personal target ranks, target LP, performance goals, session plans, and a target date for the climb.

Local history

Saves small local rank snapshots so we can build our own progression graph over time without publishing player data.

Privacy and scope

This is a small personal project for two players. It is not a commercial service and is not intended as a public matchmaking, scouting, or ranking product. The live tool runs locally on the user's computer. API keys are not embedded in this public page and should not be exposed in client-side code.

The public page exists only to document the project, its purpose, and its user flow for Riot developer registration.

User flow

1. Launch the local dashboard.
2. Authenticate API requests with a private Riot API key.
3. Refresh current ranked and match data.
4. Review duo performance and improvement trends.
5. Set personal rank/performance goals.
6. Track progress across future sessions.
