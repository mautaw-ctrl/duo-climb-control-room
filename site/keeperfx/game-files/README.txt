MIRACLE442 OS - KeeperFX web data pack folder

Put the freely redistributable/replacement game data pack in this folder.

Expected structure:

game-files/
  data/
    bluepal.dat
    bluepall.dat
    dogpal.pal
    hitpall.dat
    lightng.pal
    main.pal
    mapfadeg.dat
    redpal.col
    redpall.dat
    slab0-0.dat
    slab0-1.dat
    vampal.pal
    whitepal.col

  sound/
    atmos1.sbk
    atmos2.sbk
    bullfrog.sbk

The browser launcher checks these exact compatibility filenames.
No commercial Dungeon Keeper game files are included here.
